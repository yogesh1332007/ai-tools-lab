# AI Tools Lab

A practical learning repository for exploring Artificial Intelligence tools, Git, GitHub, code assistants, and AI-assisted software development.

## Project Description

This project is created as part of the AI Tools Lab course. It demonstrates practical use of Git and GitHub for version control, branching, commits, pull requests, and AI-assisted programming.

The repository contains simple Python programs developed and managed using Git and GitHub workflows.

## Features

- Basic Python programming examples
- Bubble Sort implementation
- Utility functions
- Git branching and version control
- Pull Request workflow
- AI-assisted code development
